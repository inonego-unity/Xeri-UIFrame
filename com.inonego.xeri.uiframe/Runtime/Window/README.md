# Xeri UIFrame Window

이 폴더는 UIFrame 위에서 동작하는 선택 모듈 Window를 구현합니다. Window Workspace, Window Session, Registry, UITK panel/interaction과 persistence integration을 포함하며, Window 목록 표시에는 Tray를 사용합니다.

일반 Runtime 진입점은 `XeriWindowWorkspace`입니다.
