# Xeri UI 관리 도구

Unity 메뉴 **Tools > Xeri UI > 관리 도구 열기**에서 엽니다. 도킹할 수 있는 UI Toolkit 편집기 창이며, 처음 열 때는 에디터 가운데에 1280×800 크기로 열립니다.

## 화면 구성

창 상단 막대에는 다섯 개의 탭, **설정 메뉴**, **검사 상태 칩**이 있습니다.

- **설정 메뉴**: 현재 관리 중인 설정 에셋 이름을 표시하고, 누르면 관리할 `UISettingsAsset`을 고를 수 있습니다. 목록은 프로젝트 에셋과 패키지 에셋을 구분해 보여 주며, 새 설정을 만들거나 선택을 해제할 수 있습니다. 프로젝트에 설정이 하나뿐이고 아직 직접 고르지 않았을 때만 자동으로 선택합니다. 에셋의 전체 경로는 툴팁으로 표시합니다.
- **검사 상태 칩**: `검사 전`, `재검사 필요`, `검사 실패`, `오류 n · 경고 n`, `문제 없음`을 표시합니다. 누르면 검사를 실행하고 진단 탭으로 이동합니다.

| 탭 | 기능 |
| --- | --- |
| 개요 | 왼쪽 **구성** 카드에 선택한 설정의 기본 레이아웃, 연결 대상, 입력, 초기화 모듈, 렌더링 출력, 로드된 씬 구성 요소를, 오른쪽 **진단** 카드에 검사 상태와 결과 목록을 표시합니다. 두 카드는 창 아래까지 늘어나고 넘치는 내용은 카드 안에서 스크롤합니다. 각 행을 누르면 해당 화면이나 대상으로 이동합니다. |
| 설정 | 일반·연결 대상·입력·렌더링·초기화 분류별로 설정 에셋을 편집합니다. 렌더링 분류에서 URP/HDRP 출력을 미리 보고, 적용·제거합니다. 초기화 분류에서는 이 설정을 쓰는 UI 초기화 모듈의 호스트 프리팹을 지정하고, **초기화 모듈 만들기**로 모듈 에셋을 만들면서 프로젝트 Bootstrapper 설정(`Assets/Resources/BootstrapperSettings`)에 등록하거나, 이미 있는 모듈을 **초기화 설정에 등록**할 수 있습니다. |
| 구성 > 레이아웃 | 레이아웃 에셋을 검색·생성·선택하고 레이어 표(위)와 배치 표(아래)를 편집합니다. 두 표의 높이는 처음에 약 6:4로 나뉘며 분할선으로 조절합니다. |
| 구성 > 씬 · 호스트 | 로드된 씬과 프리팹 편집 단계의 런타임·레이어 호스트·배치 호스트를 트리로 보고, 연결 상태와 Inspector를 표시합니다. |
| 진단 | 검사 범위, 아이콘이 붙은 심각도 필터(전체·오류·경고·정보, 검사 전에는 0), 검색, 결과 목록과 상세를 제공합니다. 항목을 더블 클릭하거나 상세의 대상을 누르면 해당 위치로 이동합니다. |
| 실행 | 플레이 모드에서 컨텍스트별 입력 권한·화면 스택·모달, 표현 세션의 레이어·배치, 최근 사건을 표시합니다. |

넓은 창에서는 목록과 상세를 좌우로, 좁은 창(640px 미만)에서는 위아래로 배치하고 탭은 아이콘만 표시합니다. 분할선은 끌어서 조절할 수 있습니다.

## 레이어·배치와 컬렉션 편집

레이어·배치·연결 대상·해제 입력 목록은 Xeri Core의 `[CollectionEditor]`로 편집합니다.

- 레이어는 **이름 · 레이어 ID · 순서 · 백엔드**, 배치는 **표현 ID · 레이어 ID · 순서**, 연결 대상은 **연결 ID · 레이어 ID** 열로 표시하며 표에서 바로 편집합니다.
- 관리 도구 안의 컬렉션은 Core Collection Editor의 **채움 모드**로 표시합니다. 컬렉션이 남은 높이를 여백 없이 채우고, 들어가는 행 수만큼 페이지를 나누므로 바깥 스크롤과 겹치지 않습니다. 채움 모드에서는 목록을 접지 않습니다.
- 일반 Inspector에서는 같은 컬렉션이 지정한 행 수(`VisibleRows`)로 표시되며, 목록 아래 손잡이를 끌어 높이를 조절할 수 있습니다.

값 변경은 `SerializedObject` 바인딩으로 처리하므로 Undo/Redo와 Dirty 표시는 Unity 기본 동작을 따릅니다.

## 검사 범위와 판정

- 레이어 ID와 순서의 유일성은 **해당 레이아웃 안에서만** 검사합니다. 서로 다른 레이아웃의 같은 ID는 오류가 아닙니다.
- 설정의 기본 레이아웃에만 Root 연결 대상·백엔드 지원 규칙을 적용합니다. 별도 Child Layout은 실제 부모 표현이 확인되기 전까지 호환 여부를 확정하지 않습니다.
- 검사 범위는 선택한 설정, 그 기본 레이아웃, 구성 탭에서 선택한 레이아웃, 로드된 씬의 구성 요소입니다.
- 검사 후 대상이 바뀌면 **재검사 필요**로 표시하고 이전 개수를 숨깁니다. 검사할 대상이 없으면 오류 0건을 통과로 표시하지 않습니다.
- 씬 탐색은 로드된 씬과 프리팹 편집 단계만 조회하고 미로드 씬을 열거나 수정하지 않습니다. 씬에 호스트가 없는 생성형 레이어는 누락 오류로 보지 않습니다. **등록됨**은 Runtime의 호스트 목록에 참조가 있다는 뜻이며 출력 구성의 유효성을 보증하지 않습니다.

## 렌더링 출력

설정 > 렌더링에서 현재 프로젝트의 URP 또는 HDRP 출력 도구를 사용합니다. 적용·제거는 Installer를 호출하며 실행 전에 확인을 요구합니다. 출력 설치 메뉴는 이 화면으로 통합되어 별도 메뉴 항목은 없습니다.

## 게임 내 진단창

에디터 플레이 모드와 지원되는 개발 실행 환경에서 **F8** 키로 표시·숨김을 전환합니다. 게임 내 진단창은 본체 UI Runtime의 Screen·Destination에 의존하지 않는 별도 패널이며, Runtime 초기화에 실패해도 상태를 표시할 수 있습니다. 편집기 실행 탭과 같은 진단 API(`XeriUIDiagnostics`)를 사용하며, 지원하는 명령은 **최상단 화면 닫기**뿐입니다. 출시 빌드에서의 제외 여부는 실제 Player 빌드로 확인해야 합니다.

## 화면 자산과 스타일

- 화면 구조는 `Editor/ControlCenter/Resources/Xeri/UI/ControlCenter/`의 탭별 UXML(`Shell`, `Overview`, `Settings`, `Composition`, `Diagnostics`, `Live`)에, 스타일은 같은 폴더의 `ControlCenter.uss`에 있습니다.
- `ControlCenter.uss`는 상단 **테마 토큰**(면·선·글자·강조색, 글자 크기, 간격과 높이)에서만 색과 크기를 정의하고, Light Skin은 `.xeri-cc--light`에서 같은 토큰을 덮어씁니다. 이후 영역은 번호가 붙은 주석 블록으로 구분합니다.
- Unity 기본 컨트롤(`ObjectField`, `PropertyField`, `ToolbarSearchField` 등)의 내부 요소 스타일은 바꾸지 않고 바깥 컨테이너만 지정합니다. 아이콘은 Xeri Core의 `XeriIcon`을, 심각도 아이콘은 `SeverityIndicator`를 사용합니다.

## 제한 사항

- 코드에서 동적으로 사용하는 Child Layout을 프로젝트 전체에서 자동 추론하지 않습니다.
- 실행 탭은 조회와 최상단 화면 닫기만 지원하며, 임의 Screen 생성이나 내부 컬렉션 직접 수정은 지원하지 않습니다.
